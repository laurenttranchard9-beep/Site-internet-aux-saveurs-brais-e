# Plaquettes QR code pour les tables

Le QR code ouvre **https://auxsaveursbraisee.fr/?src=qr**. Le `?src=qr` permet de voir les scans dans l'onglet Statistiques de l'espace de gestion (ligne « QR code (tables) » dans Provenance), pour les visiteurs qui acceptent le cookie.

- **`plaquettes-qr-code.pdf`** : page 1 = 4 plaquettes A6 (10,5 × 14,8 cm) sur une feuille A4 ; page 2 = 6 autocollants carrés (9 × 9 cm) sur A4. Découper le long des pointillés.
- **`qr-code-auxsaveursbraisee.png`** et **`.svg`** : le QR code seul, pour d'autres supports (vitrine, flyers, réseaux sociaux).

Impression : taille réelle (100 %, sans « ajuster à la page »), « Graphiques d'arrière-plan » coché. Sur papier autocollant, ou à glisser dans un chevalet de table. Le QR code a été testé avec le logo au centre, y compris en basse définition.
